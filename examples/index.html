cloud-image-index

A machine-readable directory of operating system cloud images published by their upstream vendors: which images exist, the exact current builds, and where to download and verify them. It is updated daily from the vendors' own sites.

This is a directory, not a distributor. Images are always downloaded from the vendor, and each entry carries the vendor's own checksums and signatures where they publish them, so clients can decide how far to trust the index.

Files

  • v1/index.json: every distro
  • v1/images.json: every current build, with its distro and release, in one file
  • v1/distros/<distro>/index.json: a distro's releases and aliases
  • v1/distros/<distro>/aliases/latest.json (also lts.json, dev.json): the builds of the release holding that alias
  • v1/distros/<distro>/releases/<release>/index.json: a release's current builds
  • v1/openapi.json: the OpenAPI description of all of the above

Browse the API documentation, rendered from v1/openapi.json.
